# MCP Client

A Python client for interacting with Model Context Protocol (MCP) servers.

## Requirements

- Python >= 3.14
- uv (recommended package manager)

## Installation

Install dependencies using uv:

```bash
uv sync
```

Or using pip:

```bash
pip install -e .
```

## Dependencies

- `mcp` - Model Context Protocol library
- `openai` - OpenAI Python SDK

## Usage

Run the client:

```bash
python main.py
```

Or using uv:

```bash
uv run main.py
```

## Development

This project uses:
- `uv` for dependency management
- `pyproject.toml` for project configuration
